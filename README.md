# Calculadora de Presión de Vapor

Calculadora interactiva de presión de vapor para múltiples componentes usando la ecuación de Antoine.

## Componentes disponibles
- Agua
- Etanol
- Benceno
- Acetona
- Tolueno

## Funcionalidades
- El usuario ingresa el componente y rango de temperaturas
- Calcula 100 puntos de presión de vapor con NumPy
- Grafica la curva con Matplotlib
- Permite comparar dos componentes en la misma gráfica
- Exporta resultados a CSV

## Tecnologías
- Python 3
- NumPy
- Matplotlib
- Pandas
